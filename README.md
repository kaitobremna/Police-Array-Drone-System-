# Police-Array-Drone-System- (Bachelor's Project)
Object detection and path tracking/prediction of fleeing suspects from drone aerial view, for use as an aid to police first responders. Includes a custom 4-way sensor multimodal hybrid fusion architecture design.

(Codebase is scattered, reflecting this repo being a collection of experiments, trained models and findings, rather than a product)
